Onam Attractions-2006

An Onam release for any hero is a prestigious project. It is normally the only time of the year when superstar films clash with each other, as they release simultaneously.

As of now a record seven films have announced that they will release for Onam. They are-

Bhargavacharitram Moonam Khandam- Mammootty- Sreenivasan-Padmapriya starrer mass masala thriller, directed by Joe Mon- Release date- Sep 1

Mahasamudram- Mohanlal, Laila starrer set in the backdrop of sea and fisdhermen, directed by S.Janardhanan. Release date- Sep 1

Don- Dileep, Gopika starrer is an action thriller directed by Shaji Kailas. Release date- Sep 5.

Janmam- Suresh Gopi, Gopika, action thriller directed by Joshy. Release date- Sep 5

Aanachantham- Jayaram and Remya starrer is a family entertainer laced with humour, direcetd by Jayaraj. Release date- Sep 1

Classmates- This youth film has young brigade of Pritviraj, Indrajeet, Kavya and others, direcetd by Lal Jose. Release date- Aug 25

Red Salute- Kalabhavan Mani is going all out to woo the B and C class audience through this action thriller directed by Vinod Vijayan. Release date- Sep 1
